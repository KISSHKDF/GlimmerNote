# 题干标记：加点（着重号）必须能被看见

> 立规日：2026-10-25 晚 ｜ 起因：用户把 Y0001 印出来拍过来，原话
> 「从印刷体来看，你的打点能力很差，全库都是这样，如何加强？」
> ｜ 裁判：`src\tools\_着重号门禁.mjs`（唯一入口）｜ 回归：`tests\neg-emphasis-mark.cjs`
> ｜ 样式：`src\app\css\app.css` 的 `.rd` / `.rd-above`

## 一、事故现场（先把"是什么坏了"说清）

Y0001「下列句中**加点**字词古今义相同的一项是（ ）」印出来是四个光秃秃的选项，
一个字都没有点——这道题**没法做**（题目条件就写在"哪个字被点出来"上）。

根因不是标错了字，而是：

| 层 | 事实 |
|---|---|
| 数据 | 题干用 `<span class="rd">制</span>` 标加点字，全库 14 处 / 3 张卡，标的位置都对 |
| 样式 | **`app.css` 里从来没有 `.rd` 规则**——2026-10-25 新建的 v2 界面没有，运行区上一版也没有 |
| 结果 | 标记在 DOM 里、在盲解清稿里（`字+组合点`）都在，只有**纸面上**消失 |

同一份数据在屏幕上看是"题干里有个 span"，在纸上看到的是普通字。**这类缺陷只在纸上暴露**，
和"答案不全 / 图上作答白留框 / 横线写不下"是同一族（见 `docs\作答契约.md`）。

## 二、两种"点"，两个 class（混用必有一类印错）

| class | 语义 | 点在哪 | 例 |
|---|---|---|---|
| `.rd` | 语文**着重号**（加点字） | 字的**下方** | Y0001「增其旧**制**」 |
| `.rd rd-above` | 数学**循环节** | 字的**上方** | M0014「2.0**5****0**」＝2.05050… |

判定依据：题面出现「加点/着重号」→ 用 `.rd`；题面出现「循环小数/循环节」→ 用 `.rd rd-above`。
两者都写进 `<span class="…">` 里那一个字符上，**一个字一个标记**。

## 三、为什么自绘圆点而不用 `text-emphasis`

实测（Edge headless → `--print-to-pdf` → 栅格化，A4 / 12.5pt）：

| 做法 | 屏幕上 | 打印出来 |
|---|---|---|
| `text-emphasis: filled dot` / `-webkit-text-emphasis` | 有点 | 点直径仅约 0.14em 且明显发灰，**几乎看不见** |
| 自绘伪元素圆点（`::after` + 绝对定位 + `currentColor`） | 有点 | 清晰、位置可控 |
| `border-bottom: dotted` | 像下划线 | 与着重号不是一回事 |

所以 `.rd` 用自绘点：`.15em` 见方、`background: currentColor`、`bottom: -.34em`（字下），
`.rd-above` 把 `bottom:auto; top:-.06em`（字上）。屏幕与打印同一条规则（打印态吃 `.sheet` 样式）。

## 四、判据（`_着重号门禁.mjs`，缺一条就红）

1. 题面（题干纯文本 + 索引 `question`）出现「加点/着重号」⇒ 题干里**必须**有 `.rd` 标记；
2. 每个 `.rd` **恰好一个字符**（点多落在一组字中间＝等于没标）；
3. `.rd` 不许写进 `<svg>`（图上的点画在图形层）；
4. `app.css` 里 `.rd` 必须有**可见**样式（存在 & 画得出点 & 没被 `display:none` 藏起来）；
5. 用了 `.rd` 但题面不提加点 ⇒ 提示改用 `.rd rd-above`（只提示不阻断）。

**为什么第 4 条也算门禁**：这次事故的唯一致命点就是"样式被删了，谁都不知道"。
删一条 CSS 不会有任何报错，纸面直接退回"没点"——所以把"样式必须存在且画得出点"写成断言，
`tests\neg-emphasis-mark.cjs` 的 D3/D4/D5 就是它的阴性自证（删掉/藏起来/不画点都必须红）。

## 五、新增一道要用"加点"的题时

1. 题干里把要加点的字包起来：`<span class="rd">制</span>`（一字一个 span）；
2. 循环节用 `<span class="rd rd-above">5</span>`；
3. `node src\tools\_着重号门禁.mjs 门禁` 必须绿；
4. 印前用真渲染看一眼（`render-check` 之类）：**加点必须肉眼可见**，且点在该点的字上；
5. 改 `.rd` 的样式后跑 `node tests\neg-emphasis-mark.cjs`（样式被删会红）。

## 六、已知边界

- **多字连标**：一个字一个 span 是硬规则。真要标一串（如"加点句子"），改用下划线题型或图。
- **竖排/横排**：本仓只出横排 A4，`.rd` 的点固定在下；若要竖排需另配 `writing-mode` 规则。
- **打印灰度**：自绘点用 `currentColor`，黑字即黑点，灰度打印不丢；`text-emphasis` 的灰点会丢。
