## 一、事故现场（先把"是什么坏了"说清）

E0017（某七年级英语卡·读音判断 2 处合卡）印出来是：

```
( ) 3. classm<u>a</u>te        <u>a</u>ny
( ) 5. th<u>e</u>se        <u>e</u>nergy
```

两处坏，且**互相放大**：

| # | 坏了什么 | 读者看到什么 |
|---|---|---|
| ① | 画线部分本该是真标签 `<u>a</u>`，落盘时变成了**实体** `&lt;u&gt;a&lt;/u&gt;` | 题面上印出**字面的 "<u>a</u>"** —— 八个字符的垃圾，不是下划线 |
| ② | 只抄了小题（3、5），**没抄大题指令** | 不知道要做什么，也不知道 **S/D 各代表什么** |

第 ① 条的**铁证**：同一张卡的**索引 `question` 字段里是真标签**、题干.html 里是实体化标签。
同一处标记两种编码 ⇒ 不是录入笔误，是**转义层被套了两次**：

```
AI 回传的 questionText:   classm<u>a</u>te        ← 已经是真标签
入库器 escapeHtml() 一转:  classm&lt;u&gt;a&lt;/u&gt;te  ← 又转了一遍
浏览器解码后:              classm<u>a</u>te        ← 当成字面文本印出来
```

第 ② 条的**决定性事实**：大题指令**不在索引里**。索引 `question` 只做兜底
（`src\app\js\views\paper.js:490`）—— 题干.html 一旦有内容，索引里的内容**根本不会被印出来**。
所以"抄题干"这一步**必须**自己把大题指令带进来。

## 二、为什么四道现有门禁都没拦住

这是本次事故最值得记住的部分：**不是门禁不够多，是它们查的根本不是同一件事**。

| 门禁 | 它查什么 | 为什么管不着 E0017 |
|---|---|---|
| `_作答门禁.mjs` | 空位数 / 逐空答案 | E0017 没有空位，它管不着 |
| `_着重号门禁.mjs` | `.rd` 加点标记的**样式** | E0017 用的是 `<u>` 不是 `.rd` |
| `_配图门禁.mjs` | 图资产 | E0017 无图，它管不着 |
| `_盲解复核.mjs` | 两路结论是否**一致** | 它的指纹恰恰**算在乱码题面上**（实测 `fp=c397862e942c` = 乱码文本的 v2 指纹） |

最后一行是本次事故最反直觉的地方：**盲解不但没拦住乱码，反而把乱码固化成了"已通过"的凭据**。
指纹算在什么题面上，"双盲一致"就证明什么题面没问题 —— 题面本身坏了，指纹照样一致。

⇒ 缺的那一维是：**题面本身能不能读懂**。

## 三、判据（`_题干门禁.mjs`，缺一条就红）

分**两级** —— 这是刻意的，不是妥协：

### A 级：数据损坏 ⇒ **阻断**（印出去就是垃圾，绝不能印）

| # | 判据 | 为什么这么判 |
|---|---|---|
| ① | **实体化的标签**：`&lt;u&gt;` / `&lt;span …&gt;`（含双重转义 `&amp;lt;`） | 浏览器解码后会把 "<u>a</u>" 当字面文本印出来 |
| ② | **正文印出字面标签**：源码里的真标签挖掉后，实体解码才变成标签的东西 | 与①是同一条证据链的两端 |
| ③ | **标记不配对**：开闭数不等，或栈式良构性错乱（`<b><i></b></i>`） | 净化器剥标签后内容会被吞掉，读者少看到一块 |
| ⑤ | **语篇残篇**：⑤a 题干含**残篇自述占位**（`本页为后半` / `前半在` 这类）；⑤b 某个 `<p>` **以省略号开头且该段纯文本 ≥100 字符** | 跨页语篇（p31→p32）只抄了后半页 ⇒ 读者读不到标题与主题句（E0058/E0059 事故） |
| ⑦ | **该画线却没画线**：题干纯文本里出现 `画线` / `划线`，但**整份题干一个 `<u>` 都没有** | 这类题（判断读音异同 / 按画线部分归类 / 对画线部分提问 / 替换或翻译画线部分）**不标出画线就没法作答** —— 印出去等于一道做不了的题（用户 2026-11-08 报障：「单词画线的字母，你在印刷版中没有体现出哪个字母画线了」） |

⚠ **① 必须只认「实体化的*标签*」**：数学不等号 `&lt;` / `&gt;`（后面跟数字/中文/空格）
**不算**。全库 52 处 `&lt;`/`&gt;` **全是合法不等号**（20 张数学/物理卡）——
判据宽到"见到 `&lt;` 就红"会误报 20 张卡。判别法：`&lt;` 后紧跟**字母或斜杠** ⇒ 标签。

⚠ **② 必须先把真标签挖掉再解码**：卡片**本来就合法**用 `<i>` `<sub>` `<span class="fr">` `<svg>`
这些内联标记（斜体、上下标、分数、图形）—— 它们在源码里就是真标签，是题面的一部分。
第一版判据写成"解码后有标签就红"，结果**全库 590 张全误报**。

⚠ **⑤a 只认「残篇自述」的具体措辞，不认「跨页」这个词**：修复后的抬头是
`【短文原文（课时练 7A 第31–32页·技能拓展提升 阅读短文，回答问题；跨页语篇已接成全文）】`
—— 它**提到"跨页"却已经接成全文**，必须判绿。判据宽到"见到『跨页』就红"，
修好的卡反而永远红 ⇒ 门禁失去意义（回归里有这条阴性对照）。

⚠ **⑤b 的长度门槛（≥100 字符）是判据的一部分，不是可调装饰**：
E0050（学生A）的 `<p>…like Chinese, Maths, English and (4) ______.</p>` 是**合法的引用标记**
（段首省略号，**45 字符**的问题行）。门槛去掉就误报它 —— 而误报会把整条发布链打挂
（本仓既有惯例：宁可漏判也不误报）。回归里 `ellipsisLeadParagraphs(样本, 100)` 命中 0 处、
门槛降到 1 就命中 1 处，这条对拍就是"门槛在承重"的证据。

⚠ **⑦ 的"已标"判定刻意宽松，且不与判据①重复计**：
`<u>` 出现在**任意位置**即算已标（**不必与"画线"二字同段**）——窄到"必须同段"会把
「抬头写画线要求、下面几行标画线」这种**正常形态**误报。而**实体化形态**（`&lt;u&gt;`）虽然
也算"已标"，但那属判据①（转义层套了两次），⑦ 不再报一遍：同一处问题报两条、读者会以为坏了两处，
且两条的修法不同（① 改编码、⑦ 补标记）。回归里这两条都有对拍。
⚠ 反向的边界同样要守住：**没提"画线"的题，即使一个 `<u>` 都没有也不红** ——
判据宽到"没 `<u>` 就红"会把全库的数学题、语文题一起打挂（回归里有这条阴性对照）。

### B 级：内容欠完整 ⇒ **只报告，不阻断**

| # | 判据 | 为什么这么判 |
|---|---|---|
| ④ | **题干不自足**：题号是**孤儿号**（最小号 > 1）**且**题干纯文本里找不到任何大题指令（大题标题行 `一、`/`二、`…、或 `【…】` 自述块、或含指令词） | 两个条件**同时成立**才算 |
| ⑥ | **长段未分段**：最长段落纯文本 ≥400 字符 | 原文多段被拍平成一个 `<p>`，读者看不出段落边界；列出来供人工回原卷核对 |
| ⑧ | **语音类题没有画线标记**：题干 / 索引 `question` / 来源 / 类型命中 `语音`/`读音`/`发音`/`音标`/`重音`/`Pronunciation`，却无 `<u>` | 这类里可能只是题干引用了原题的词、画线在别处（语境另有出处）—— 机器判不了，列出待核清单供人工回原卷核对 |

⚠ **必须两个条件同时成立**：填空题**本身自带语境**（「蜡烛燃烧是（填"放热"或"吸热"）反应。」）
是**自足**的。只按"没有指令词"判，实测会把 **359 张**卡全误报。

⚠ **题号抽取必须先剥行首答题括号**：事故样本的形态是 `( ) 3. classm…` ——
括号与数字之间隔着 `)`，不先剥就**命中不了已知事故样本** ⇒ 门禁形同虚设。

**为什么 ④ 只报告**：存量 39 张是 2026-10-22 那批的历史欠账。整改要**逐张回原卷**核对大题，
批量套模板会把指令抄错 —— **抄错比不抄更坏**。清单登记在库根 `_整改台账.md`（B-8）。
门禁把它报出来（让人看得见），但不让存量把整条发布链一次打挂。

**为什么 ⑥ 只报告**：分段对不对**只能回原卷核**（有的原文本来就只有一个长段），
机器判不了"该不该分段"；而"照 400 字符一刀切地阻断"会把一批正常的长语篇卡一起打挂。
⇒ 列出清单（`--json` 在 `longParagraphs`，人类模式在"⑥ 段"），人工核对。

**为什么 ⑤ 必须阻断**（与 ④⑥ 分级相反）：残篇**不是"抄得少"而是"抄错了对象"**——
题干以省略号起头、还自带"本页为后半"的占位，说明这一页只是半篇，读者拿不到标题与主题句，
题就**做不了**（与 E0017 的乱码同类：印出去就是废题）。⑤ 命中的是**新出现的坏卡**，
数量可数（真实库修复前 2 张、修复后 0 张），不像 ④ 那样是几十张历史存量。

**为什么 ⑦ 必须阻断**（与 ④⑥⑧ 分级相反）：提到"画线"却一处画线都没标，读者**看不出哪个字母
画了线**，判断读音异同 / 按画线归类 / 对画线部分提问 / 替换或翻译画线部分这些题就**没法作答**
—— 与 ⑤ 同类（印出去就是废题），且数量可数（真实库实测 6 张）。⇒ `--json` 计数在
`stats.underlineMissing`，清单在 `problems`。

**为什么 ⑧ 只报告**：语音类关键词（尤其"来源/类型"里的 `Pronunciation`）**不等于**这道题就该有画线
—— 它可能只是题干引用了原题里的词、画线落在别处，也可能这道题本来就不画线。机器判不了，
只能列出清单（`--json` 在 `phoneticNoUnderline`，人类模式在"⑧ 段"）人工回原卷核对；
判成阻断会把一批**正常卡**一起打挂（与 ④⑥ 同一条分级理由：宁可漏判也不误报）。

## 四、入库侧：错在入库那一刻就看得见

`_录题入库.mjs` 的 `escapeHtml()` 改成**白名单式**：

| 输入 | 现在的行为 |
|---|---|
| `<u>a</u>`（画线部分） | **原样保留**（丢了标记题就做不了） |
| `<span class="rd">制</span>`（着重点） | 原样保留 |
| `<i>` `<sub>` `<sup>` `<span class="fr">` | 原样保留 |
| `&lt;u&gt;`（实体化标签） | **抛错拒收**（不写盘） |
| `&amp;lt;u&amp;gt;`（双重转义） | **抛错拒收** |
| `<script>` / 带 `on*` 属性的标签 | 转义 |
| `x &lt; 3`（数学不等号） | 放行（不误拒） |

另有两条**行级**拒收（与上表同处、同一风格：写盘前拦，不静默落盘）：

| 输入（`questionText`） | 现在的行为 |
|---|---|
| 提到 `画线` / `划线`，却一个 `<u>` 都没有 | **抛错拒收**（判据⑦的入库侧同款；不写盘） |
| 提到 `画线` / `划线`，画线用实体化 `&lt;u&gt;` 表示 | 归上表"实体化标签"那条拒收（不重复报两条） |

实现用**占位符**（摘出 → 转义 → 放回）。
⚠ **不能**"先转义、再按标签名还原" —— 那会把 `<script>` 一起还原出来。

配方侧（`recipes\ingest-*\prompt.md`）加了同款硬规矩与自检项，
反例库记了 A-13（自己转义成实体）与 A-14（只抄小题不带大题指令），
2026-11-08 又各加了一条硬规矩 + 一条反例：**语音/画线类题必须把被画线的字母或短语用 `<u>` 原样括出来**
（`classm<u>a</u>te`、`6. y<u>e</u>s  h<u>e</u>lp`、`The woman is <u>80 years old</u>.`）。

## 六、已知边界

- **④ 的判据是启发式**：它认"大题标题行 / 【…】自述块 / 指令词"三种形态。
  大题指令写成别的样子（比如只有一句"按要求作答"）可能被漏判。
  漏判的后果是轻症（读者可能猜得到要做什么），比误报好。
- **孤儿号 ≠ 一定不自足**：整题卡保留原卷题号（如 `21. (6分)比较 2a 与 a 的大小.`）是正常的 ——
  ④ 的第二个条件（无大题指令）正是用来区分这两种情况的。
- **⑤a 是措辞判据**：只认 `本页为后半` / `前半在` / `本页为前半` 这类**自述占位**。
  只抄半页却**不留任何自述**的卡（省略号也不再段首），⑤a 抓不到 —— 宁可漏判：
  把判据放宽到"见到『跨页』"就会连**修好的卡**一起红。
- **⑤b 只认"段首"省略号**：真实事故样本的 `<p>` 前面还挂着一句旁注
  （`（跨页语篇：短文前半在 p31，本页为后半）…happy and healthy.`），
  它的段首不是省略号 —— 那张卡是被 **⑤a** 命中的；⑤b 是"没有自述占位、正文却从半句开始"
  这一形态的第二张网。把判据放宽到"段中出现省略号"会误报大量**合法的引用**（E0050 就是）。
- **⑥ 的 400 字符是经验门槛**：它只保证"值得回原卷看一眼"，不保证"一定该分段"。
- **⑦ 只认"画线 / 划线"这两个词**：原卷用别的说法（"下划线的部分""带有下划线的词"）而正文又真没标，
  ⑦ 抓不到 —— 宁可漏判。判据宽到"见到『下划线』"会去撞数学题的裸下划线空位（`______`）。
- **⑦ 的"已标"只认 `<u>`**：若某张卡用别的标记表示画线（如 `<span class="underline">`），
  ⑦ 会判它"没标"。实测真库没有这种形态；真出现时应当统一到 `<u>`，而不是放宽判据
  （放宽会把"标了但标错地方"一起放行）。
- **⑧ 的关键词命中"来源/类型"，天然偏宽**：来源里带 `Pronunciation` 的卡（整个 Period 5 都是）
  都会进待核清单，其中多数本来就该判绿 —— 所以它**只报告**，清单要人过，不是待修列表。
- **⑧ 与 ⑦ 可能同时命中**：提到"画线"的语音题会既被 ⑦ 阻断、又进 ⑧ 清单；
  这是刻意的（⑦ 是判据、⑧ 是清单口径），不是重复计。
- **盲解指纹算在题面上**：改了题干 ⇒ 指纹变 ⇒ 旧结论失效（`待重盲解`）⇒ 必须重跑双路。
  这是**保护机制**（E0017 改完后立刻自动失效，逼着重跑），但也意味着**改题干有代价**：要重跑盲解。
