# 一题多问：只收错的小问

❌ 第 12 题只有 (2) 错，却把「第12题(1)」和「第12题(2)」收成两条错题。

✅ 应该是：只收 (2) 一条，`source` 写「第12题(2)」，题干里带上 (1) 的条件。

**为什么**：(1) 是全对的，收进来就是假错题；同一道题拆成多条会让同一个错误被统计两次，
错因图谱出现"同一个知识点错了两遍"的假象，复习调度也会被重复的卡挤占。

🔴 **但「只收错的那一问」≠「答案只答错的那一问」（2026-11-26 用户报障）**

用户原话：「拾光小册，某学生，m0063，问了两个问题，但是给家长用的答案只是回答了第二问，
为什么不把第一问的答案也加上？」

❌ 题干抄了整道大题（(1)(2) 都在，卷面会让孩子做两问），答案却只写错的那一问：
`(2) 降价8元` ⇒ 家长拿答案册批改时，卷面上的 (1) **没有答案可对**。

✅ 应该是：答案**逐问标注**，每一问都给结论：
`(1) 月平均增长率25%；(2) 降价8元`

**为什么**：收卡是"只收错的那一问"（不制造假错题），**答题是"每一问都要答"**
（家长靠答案册批改卷面）。这两件事不矛盾：
- 错的那一问 → 写得**详细**（它是这张卡的考点）；
- 没错的那一问 → **给结论**（一行就够），让家长有东西可对。

⚠ 填空题例外：题干里有横线的那些空，答案进 `answerSlots`（逐空），`answer` 里不必重复。
