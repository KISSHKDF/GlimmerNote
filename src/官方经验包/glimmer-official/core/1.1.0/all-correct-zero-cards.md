# 整页全对：0 卡是合法结果

❌ 整页照片上孩子作答全对（红笔认可、独立验算无误），AGENT 硬挑一题"看起来危险"录入，
   制造了一张假错题——复习池被不存在的错误占用，孩子的"连对"记录被打破。

✅ 应该是：逐题验算确认全对 ⇒ `cards: []`（空数组），`pageSummary` 照填（总数/无错题），
   有疑处的题放 `skipped` 并写原因。程序会登记「整页无错题」，闭环完成。

**为什么**：错题本的价值取决于"录进去的都是真错"。为凑数录入的全对题是**假数据**，
它比少录一张伤害更大——少录下次还会拍，假错题会一直占着复习调度。宁可 0 卡，不可造错。
