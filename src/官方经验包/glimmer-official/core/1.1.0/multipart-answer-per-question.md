# 多问整题：答案要逐问标注

❌ 题干是整道大题（(1)(2) 都在，卷面会让孩子做两问），`answer` 却只写了错的那一问：
`降价8元` ⇒ 答案册上卷面里的 (1) **一行字都没有** ⇒ 家长判不了。

✅ 应该是：`answer` **逐问标注**，每一问都给结论：
`(1) 月平均增长率25%；(2) 降价8元`

**为什么**：家长拿答案册批改卷面，**要的是"卷面每一问的答案在哪"**。
一段没编号的散文答案，家长得自己猜哪句答哪一问；只答一问，猜都无从猜起。
⇒ 编号是**给人看的路标**，不是排版花招。

**怎么写**：
- 错的那一问 → 写得**详细**（它是这张卡的考点）；
- 没错的那一问 → **给结论**（一行就够）；
- 卷面编号怎么印，答案就怎么标（`(1)` `（1）` 都认）。

⚠ 两个例外（别硬套）：
- **填空题**：题干里有横线的那些空，答案进 `answerSlots`（逐空），`answer` 里不必重复；
- **选择题**（`answerMode=none`）：`(1)(2)(3)(4)` 是四个待判断的**说法**，答案是 `A/B/C/D` 一个。

⚠ **只被引用的小问不算数**：`由第(1)问求得` `利用(2)中的等式` ⇒ (1) 只是依赖，
答案不要求为它单列。真正要看的是**卷面让孩子做**的那些问。
