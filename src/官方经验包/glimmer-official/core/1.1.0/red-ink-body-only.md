# teacherAnswer 只抄红字本体

❌ 卷面红字写「✓ 订正：m₂l/(2(m₁+m₂))」，回传把 `teacherAnswer` 填成
   「红笔订正：m₂l/(2(m₁+m₂))」——入库器的红字比对是 NFKC+去空白后的**字面**比对，
   前缀文字让它永远与采用答案不一致 ⇒ 假阳性"红字异议"，组卷前要人工裁决。

✅ 应该是：`teacherAnswer: "m₂l/(2(m₁+m₂))"`（红字写了什么就抄什么，**只有答案本体**）；
   "这是订正笔迹、写在题旁"这类描述进 `notes` 或 `inkAttribution`。

**为什么**：红字比对是机器对机器的字面对账，不是语义理解。加一个字，比对就失真；
失真的代价是给每张卡挂一个假异议——人要一张张裁决，比漏登一张题更费人。
