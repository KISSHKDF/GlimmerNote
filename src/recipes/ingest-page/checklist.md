# 整页录入 · 人工验收清单

> **这不是给 AI 看的，是给你看的。**
> AI 一次能给好几条，所以**抽查**比逐条看更重要。

## 必做 3 步

1. **先核对数字。** 看 `pageSummary.markedWrong` 说"标出几处错"，你自己扫一眼照片数一遍。
   **数字差得远 → 整批退回重做，别逐条修。** 逐条修永远修不完，而且你会漏掉它没报出来的那些。
2. **看 `skipped`。** 它主动跳过了哪几道、为什么。**跳对了吗？**
   宁它多跳一条，也别它硬猜一条。
3. **随机抽 2 条**，逐字核对题面 + 核对"孩子答案 vs 正确答案"有没有串。

## 高危信号（出现任一条，整批重做）

| 信号 | 说明 |
|---|---|
| `cards` 里出现了只有 √ 的题 | 它把对的题当错的收了 |
| 某条 `confidence: "low"` 但 `answer` 填得很完整 | 低置信度却给了确定答案，多半是编的 |
| `questionText` 比照片"通顺" | 改写过 |
| 同一道题出现两条 | 拆重了 |
| `skipped` 是空数组、但照片上明明有判不准的题 | **它在装懂** |
| `pageSummary.markedWrong` 与 `cards` 条数对不上，且没在 note 解释 | 数字对不上账，整批不可信 |
| `answerSource: "官方答案"` 但 note 里没有站点名/出处（2026-11-05 新增） | **假装查过**——来源造假，比没查严重 |
| `answerSourceNote` 里出现学生化名/班级/学校/文件路径（2026-11-05 新增） | 检索词隐私红线被踩，这条记录的来源链已被污染 |
| `answer` 的内容直接抄自卷面红字（2026-11-07 新增） | **拿红字当答案** —— 卷面红字绝大部分不是老师批的（孩子自批/同学互批/家长帮批），只能作参考；答案须来自独立判卷或官方答案页 |
| 用了「老师定案」这个来源（2026-11-07 新增） | 该来源已废除 —— 即使确认是老师写的，红字也不作定案标准 |

## 一次处理多少

- **一页一次。** 不要一次丢十页——判错准确率会明显下降。
- 判错是这活里唯一"必须准"的一步：判错了，后面转录再准也没用。

## 想让它更准的两个技巧

1. 拍照时**把整页四边都拍进去**（不要切边），让它能数清一共几题。
2. 光线均匀、不要有阴影。**红笔在阴影里会看成黑笔**，判错的基础就没了。

## 什么时候该整页退回

- 数出来的题数与 `pageSummary.totalQuestions` 差 2 以上
- 有明确错题（红叉很清楚）却没出现在 `cards` 里
- 出现了"孩子全对"的题被收进来

**退回不是失败，收错才是。**
