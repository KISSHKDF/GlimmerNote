# 错因分类（唯一口径：K / L / S 三层，共 16 类）

> 这一层是判错因的**唯一标准**。分类学来自真实题库的长年累积，不是通用模板。
> 通用模板喜欢用「粗心」「马虎」这类词——**那是最没用的一类判定**，因为它不能指导任何一个动作。
> 你必须落到下面 16 个编码之一，并写清"错在哪一步"。

## 编码总表

### K 知识性（概念 / 公式 / 法则没掌握）

| 编码 | 名称 | 典型表现 |
|---|---|---|
| `K1` | 概念不清 | 混淆相反数/绝对值/倒数定义；正负数意义不明 |
| `K2` | 法则误用 | 符号法则、去括号法则、幂的运算法则用错 |
| `K3` | 公式记错 | 公式形式、适用条件记错 |
| `K4` | 定理条件遗漏 | 忽略前提条件（定义域、取等条件等） |
| `K5` | 固定搭配记错 | 短语整体形式/介词/单复数记错 |
| `K6` | 词形变化漏写 | 该用复数时漏词尾 -s；动词词尾变化漏写 |
| `K7` | 语序/成分位置错 | 副词、状语、宾语位置照搬母语语序 |

### L 逻辑性（推理链问题）

| 编码 | 名称 | 典型表现 |
|---|---|---|
| `L1` | 分类不全 | 分类讨论漏情况（绝对值化简漏负分支、几何多解只写一个） |
| `L2` | 推理断链 | 步骤跳跃、依据缺失、结论对但没有任何推导 |
| `L3` | 转化不等价 | 变形过程中改变题意、丢解或增解 |
| `L4` | 句子成分缺失 | 并列/从句结构缺成分 |

### S 习惯性（运算与策略——"粗心"的真面目）

| 编码 | 名称 | 典型表现 |
|---|---|---|
| `S1` | 符号运算错 | 加减号处理错、负负得正用错 |
| `S2` | 审题漏条件 | 看漏关键词、单位、范围限定 |
| `S3` | 跳步/并步 | 口算连跳多步导致出错 |
| `S4` | 抄写笔误 | 上一步对、下一步抄错数字 |
| `S5` | 答题不规范 | 符号偷换；跳过必要步骤；问"依据"不答法则名称 |

## 怎么选（判据顺序）

按这个顺序问，第一个成立的就是答案：

1. **是不是根本没懂这个知识点？** → `K1`–`K4`
   - 语言类换成 `K5`–`K7`
2. **是不是懂，但推理链断了？** → `L1`（漏情况）／`L2`（跳步）／`L3`（变形不等价）
3. **是不是方法思路都对，只在执行上出错？** → `S` 系
   - 符号 → `S1`；漏看条件 → `S2`；连跳 → `S3`；抄错 → `S4`；格式/规则 → `S5`

## 三条硬规矩

1. **不许用"粗心"当答案。** 绝大多数被称为粗心的错误，真实原因是 `K` 或 `L`。你必须继续追问，落到具体一步。
2. **`causeNote` 必须写"错在哪一步"，不能只写标签。**
   - ❌ `"causeNote": "粗心"`
   - ✅ `"causeNote": "把 −16−3 当成减法算成 −13，实际是两个负数相加应为 −(16+3)=−19"`
3. **过程错但答案对，也算错。** 凑数、代答案回去验、只写结论没推导——按 `L2` 或 `S5` 记，不能因为答案对就放过。

## `causeLayer` 不需要你填

程序会从 `causeCode` 的首字母自动导出（`K1` → `K`）。你只要保证编码正确。
