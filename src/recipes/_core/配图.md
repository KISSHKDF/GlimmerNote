# 配图规范（适用于所有学科、所有学段）

> 这一层由官方维护，所有配方都会自动带上。**不要在别的配方里重复它。**
> 违反任一条，这张卡的配图就不合格（门禁会拦）。

## 零、为什么有这一层

**配图的质量 = 这道题能不能做。** 图糊了、图上有孩子的笔迹、图和题干对不上，
孩子拿到卷子就是一道做不了的题；图上带着答案，重做卷等于泄答案。

本层的存在理由不是"好看"，是三条硬约束：

1. **看得清**（分辨率够、没畸变）——糊图读不出条件。
2. **没有泄题**（不含孩子的作答与红笔）——否则重做卷没用。
3. **和题干对得上**（是这一道题的那张图，不是同题异版）。

## 一、三级来源：按顺序试，不得跳级

**第 1 级 · 上网找图（首选）**

中小学教辅题绝大多数已电子化，公开题库上有**干净印刷版原图**：
菁优网（jyeoo.com）、21世纪教育网（zy.21cnjy.com）、二一教育、教习网（51jiaoxi.com）、
作业帮（zuoyebang.com）、精英家教网（1010jiaojiao.com）、青果学院等。

- **必须精确配对**：找的不是"同考点题"，是**同一道题**。核对判据（按顺序核，缺一不可）：
  1. 题干文字**逐字一致**（去掉题号分值后比对）；
  2. 关键数据一致（如本题 `m=3`、`y=6/x`、装置图的元件与连接顺序）；
  3. 小问序号与个数一致；
  4. 图的**内容**与本题条件对应（不是同图异题）。
- **精确配对失败 ⇒ 换站继续找**，不是直接降级裁图。至少试 2–3 个站。
- **隐私红线（同 base.md 第 10 条）**：检索词只含题干文字，禁带学生化名/学校/班级/卷面文件名。
- **命中了 ⇒ `notes` 写清出处**：`来源=网上题库原图；站点=<站名>；页面=<url 或题号>`。
- **同时命中了答案** ⇒ 答案来源写 `官方答案` + 站点（与 base.md 第 10 条一致）。

**第 2 级 · 清洗裁图（次选）**

**找不到干净原图**时，才用原卷上的图，但**必须清洗**后再入库。清洗至少做这三件事：

| 要处理的问题 | 判据 | 怎么修 |
|---|---|---|
| **孩子笔迹 / 红笔批改** | 图上出现红、黑手写笔画 | 去除对应色相的笔画，保留印刷体 |
| **拍照畸变 / 透视扭曲 / 倾斜** | 直线不直、页面边缘弯曲 | 透视矫正 + 旋转摆正 |
| **分辨率不足 / 发糊** | 图边在印刷尺寸下看不清线条 | 去噪 + 对比度拉伸 + 锐化 + 放大 |

- **清洗后的图必须仍然可读**。清洗是为了去掉干扰，不是把图毁掉。
- **清洗改变了图的内容**（例如去掉了题目条件所依赖的标注）⇒ 这张图不可用，回第 1 级或第 3 级。
- **清洗后的图要能追溯**：`_裁图记录.json` 里写清 `清洗=<做了什么>`，
  台账 `ref` 里写清 `清洗：去红笔/矫正/增强/2x`。

**第 3 级 · 矢量重画（兜底）**

前两级都不行，或图形本身是几何/函数/电路等**可精确复现**的图时，**动手画**：

- 画成 **SVG 内联在 `题干.html`**（`kind: svg`）。矢量图任意缩放不糊，是印刷质量最好的形态。
- 画之前先在 `notes` 写清图里有哪些要素、方向、标注，便于复核。
- 矢量重画的图**必须双路盲解核对**（见第三节）：两个独立解题方分别读图解题，结论一致才算通过。

**降级不是自由裁量**：从第 1 级降到第 2 级、或从第 2 级降到第 3 级，
都要在 `notes` 里**写明"因为什么降级"**（例：`网上未找到逐字一致的原图，故用原卷裁图并清洗`）。

## 二、配图的三条禁令

1. **禁把带孩子笔迹的图直接入库**。原卷裁图未经清洗 ⇒ 违反。重做卷会泄答案。
2. **禁把糊图入库**。印刷尺寸下线条不可辨 ⇒ 违反。宁可回上一级重找。
3. **禁图题对不上**。图必须属于**这一道题**。同图异题、同题异版的图都不能用。

## 三、最后一道关：双路盲解必须跑图形层

**图配好之后，图要参与解题验证**，不能只挂在那里。

- **图形题**（题干出现"如图/见图/图中/下图"或图是题目条件）⇒ **两路盲解都必须有 `layer=fig` 的结论**。
  两路互不通气，分别读**题干 + 配图**独立解题。
- **两路结论不一致** ⇒ 以图形层结论为准回改卡面，并重跑指纹。
- **只有文字自足、图形层没跑**的图题 ⇒ **不算通过**，不许进组卷池。
- **改图即失效**：配图一改，盲解指纹失效，必须重跑双路（`_盲解复核.mjs` 的图形签名机制已覆盖内联 svg / img；
  换成本仓 `题图.jpg` 的，**换图也必须重跑**——见 `_配图门禁.mjs` 的图指纹项）。

## 四、自检清单（每次配图后逐条过）

- [ ] 第 1 级试过了吗？用了哪几个站？命中的是**同一道题**吗（逐字 + 数据 + 小问 + 图内容）？
- [ ] 若降级，`notes` 写明降级原因了吗？
- [ ] 图上有孩子的笔迹吗？红笔吗？（有 ⇒ 必须清洗或重画）
- [ ] 图清楚吗？印刷尺寸下线条可辨吗？
- [ ] 图属于这一道题吗？
- [ ] 图形题的**两路盲解都跑了图形层**吗？结论一致吗？
- [ ] 台账 `ref`/`note` 写清了图的来源与处理方式吗？
