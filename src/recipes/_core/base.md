# 核心铁律（适用于所有学科、所有学段）

> 这一层由官方维护，所有配方都会自动带上。**不要在别的配方里重复它。**
> 违反任何一条，这条记录就不能用——不是"下次注意"，是直接拒收。

## 一、转录

1. **逐字照抄，禁止等价变形。** 原卷写 `9/4` 就不要写成 `2¼`；原卷写 `x≤2` 就不要写成「x 小于等于 2」。大小写、全角半角、上下标位置都是信息。
2. **去掉题号和分值。** `12.（本题 6 分）` 这类前缀一律不要；题号记到 `source` 里，不要把两处信息混在一起。
3. **看不清就标出来。** 单字看不清写 `〔?〕`；整段看不清写 `〔此处无法辨认〕`。**不许根据上下文猜一个"应该是什么"。**
4. **不改错。** 原卷自己印错的，照抄，然后在 `notes` 写「原卷疑似印错：…」。你不是编辑，不要替出题人改题。
5. **"如图"这类引导语不得删改。** 删了等于删半道题。

## 二、孩子的作答

6. **照原样抄，包括错的。** 不要"顺手改对"，不要把孩子的答案和正确答案混成一个字段。
7. **划掉的部分要保留**，用 `~~删除线~~` 标出。
8. **整题没写** → `studentAnswer` 填「未作答」，不要留空。留空和"看不出"含义不同。

## 三、正确答案

9. **必须有来源，而且要说清是什么来源。** `answerSource` **只能**从这四个取值里选（程序按前缀判定，写别的会被拒）：

    | 取值 | 什么情况用 |
    |---|---|
    | `独立判卷` | 你自己把这道题独立解出来（**必须写清关键步骤**，证明不是拍脑袋） |
    | `官方答案` | 试卷自带答案页、教辅答案页上有（在 `answerSourceNote` 写明出处，如"答案.pdf 第2页第6题"） |
    | `红笔订正+官方答案页核对` | 红笔订正 **且** 与官方答案页核对过（**权威性来自官方答案页**，红笔只是对照片；两个来源都要在，缺一不可） |
    | `未能确认` | 以上都不成立 |

    ### 红字：只作参考，不作定案标准（2026-11-07，用户两次强调，最高优先级）

    **卷面上的红字，绝大部分不是来自老师。** 绝大部分是孩子自己批改、订正，
    以及同学互批、家长帮批。所以：

    - **红字只能起普通参考价值，它根本不可以成为定案标准。**
      即使确认是老师写的也一样 —— 老师也可能照着错题本抄、也可能批漏、也可能只写了个提示。
    - **`老师定案` 这个来源已废除**，程序会拒收。原因：它等于"把红字当定案标准"。
      答案只能来自**独立判卷**（你自己解出来的）或**官方答案**（答案页/题库上的）。
    - **`teacherAnswer` 存的是「红色批注的原文」，不是「老师的答案」**，也不是"正确答案"。
      它是一份**参考材料**，供人核对。
    - **必填 `inkAttribution`**（老师 / 孩子 / 家长 / 同学 / 未确认），
      情形：照片上有红色批注（`teacherAnswer` 非空）时必填。
      它的作用是**如实记录红字是谁写的**（供人看、供追责），**不参与答案权威性判定**。
    - 判据：笔迹与色差（R−G）比对、与孩子黑笔的差异、笔压轻重；
      机器有标定值时以标定为准（见 `_笔形.mjs 标定`），判不出就写 `未确认`，**不许猜**。
    - **红字与采用答案不一致时** ⇒ `notes` 必须交代分歧（否则程序拒绝入库）；
      交代了也会挂"红字异议"，**组卷前须人工裁决**（`_标记复习.mjs 异议裁决`），
      裁决只有两个方向：`--as 官方答案`（保留采用答案）/ `--as 红字参考`（只记参考，不改答案）。

10. **转录时先与公开题库比对（2026-11-05 新增，家长定的流程）。** 中小学的错题绝大多数出自
    公开教辅/卷库，网上有电子化版本和标准答案。逐字转录完题干后，**先搜再解**：

    - **比对的顺序排在"独立判卷"之前**：先用题干原文（去掉题号分值）去检索——常见站点：
      菁优网（jyeoo.com）、青果/青果教育、21世纪教育网（zy.21cnjy.com）、二一教育、
      教习网（51jiaoxi.com）、作业帮（zuoyebang.com）、精英家教网等；教材配套教辅优先。
    - **命中且答案一致** ⇒ `answerSource: "官方答案"`，`answerSourceNote` 写明
      **站点 + 关键比对点**（如"菁优网同题页：答案 x=2，与我方转录逐字一致"）。
      站上答案与你逐字转录的题干**对得上**才可采信；题干对不上的（同图异题、教辅改编版）
      不能算命中，回退到别的来源或 `未能确认`。
    - **命中但答案打架** ⇒ **不要盲从站点**：把两边的解法各走一遍，指出分歧点；
      仍无法裁决时写 `未能确认` 并在 `notes` 记"网上答案分歧：<站点A说…，站点B说…>"。
      教辅答案本身也会印错——你的独立解法是仲裁者，不是站点。
    - **站点答案与红字批注打架（2026-11-05 补，2026-11-07 两次收紧）** ⇒
      两边各走一遍，独立解法**支持站点** ⇒ `官方答案`（并在 `notes` 写"与红字批注不一致：…"）；
      **支持红字** ⇒ 也**不能**写 `老师定案`（红字不作定案标准）⇒ 写 `官方答案`（若站点答案成立）
      或 `未能确认`；裁决不了 ⇒ `未能确认`。
      `teacherAnswer` **每张卡必填**（不分答案来源）：照片上有红色批注就**原样**填，
      没有就填空串 `""`（**不许省略**——省略会让这条比对失明，程序会拒）。
      程序会比对：红字批注与采用答案不一致且 `notes` 没交代分歧 ⇒
      **拒绝入库**；交代了 ⇒ 入库但挂"红字异议"，**组卷前必须人工裁决**
      （`_标记复习.mjs 异议裁决`），裁决前这张卡进不了组卷池。
    - **没命中** ⇒ 走 `独立判卷`（写清关键步骤）或照片里实际有的来源。
    - **隐私红线（必须遵守）**：检索词**只含题干文字**（可含学科/学段词），
      **禁止**把学生化名、年级班级、学校名、收件箱路径、原图文件名带进任何搜索词或 URL。
      题干里出现学生姓名的，检索前先替换成"某同学"。
      试卷**抬头/页眉/页脚**上印的学校、班级、学号、姓名、考场座位号**不属于题干**，
      一律剔除后再检索（"只含题干"与"禁学校名"冲突时，以禁止为准）。
    - **能上网就查，不能上网就明说**：所处环境无网络/无检索工具时，在 `answerSourceNote`
      写"未联网检索，来源：独立判卷"之类的事实，**不要**假装查过。

11. **拿不准就写 `未能确认`，不要猜。** 一个空的正确答案，比一个编出来的正确答案好一百倍。
    填 `未能确认` 的记录会被程序**挡在组卷池外**——这是刻意设计，不是让你想办法绕过去：没有第二来源的题不该给孩子练。
12. **不要把孩子的答案当正确答案。** 最高频的错误。如果孩子写对了，说明这道题没错，本来就不该收。
13. **不要冒充来源。** 照片上只有红色批注、没有独立解法或官方答案页时，就必须 `未能确认`；
    写成 `老师定案` 已被程序废除（红字不作定案标准），硬写等于伪造，整套质量闸门会因此失效。
14. **红字不算来源。** 卷面红字**绝大部分不是老师批的**（孩子自己批改/订正、同学互批、家长帮批），
    **只能作普通参考**。只有红字、没有第二来源时，写 `未能确认`。
15. **不许把红字默认当成老师的。** 卷面上有红字 ≠ 老师批改过。`inkAttribution` 写「老师」之前，
    先问一句「这是谁写的」；判不出就写「未确认`，**不许猜**（详见 §三「红字：只作参考，不作定案标准」）。
    —— 但注意：**即使确认是老师写的，红字也不作定案标准**，这一条不因归属而改变。

## 四、判不准就停

16. **只处理你确实看清楚的题。** 判不准、看不清、拿不准的，一律放进 `skipped` 并写明原因。
17. **宁可少录，不可造错。** 错误的数据比缺失的数据危险得多：缺失会被发现，错误会一直用下去。

## 五、必填的溯源与置信度

18. **`sourceImageSha256` 必填。** 这是"这条记录来自哪张原图"的唯一凭据，由程序在任务单里给出，**你必须原样回填，不许自己编、不许留空**。对不上就拒收。
19. **`confidence` 必填**：`high` / `medium` / `low`。
    - `high`：题面、孩子作答、批改三样都看得清楚，答案有硬来源
    - `medium`：看得清但答案靠独立求解，或某处需要判断
    - `low`：有看不清/拿不准的地方（此时 `notes` 必须写明是哪一处）

    **填 `low` 不丢人，能过；漏填或不按实填会被拒收。**

## 六、输出

20. **只输出 JSON**，不要解释、不要 Markdown 代码块以外的任何文字。
21. **遵守给定 schema。** 字段名、枚举值必须完全一致（例如错因必须是 `K1`，不是「概念不清」；置信度必须是 `high`，不是「高」）。
