# 单题录入 · 人工验收清单

> **这不是给 AI 看的，是给你看的。** 程序会把这份清单一起打印出来。

## 必做 3 步

1. **先看照片，再看记录。** 不要反过来——先读 AI 的输出，你的判断就被它锚定了。
2. **核对三样**：
   - 题面是不是"原卷的替身"（有没有被改通顺）
   - 孩子的答案和正确答案有没有串（这两格最容易错）
   - `answerSource` 是不是站得住（能不能指着照片说出依据）
3. **看一眼 `confidence`**：如果是 `low`，`notes` 里必须写清哪一处看不清。没写就是不合格。

## 高危信号（出现任一条，这条记录不能收）

| 信号 | 说明 |
|---|---|
| `questionText` 比照片"通顺" | 被改写过。转录件不是读物，是原卷的替身 |
| `answer` 有值但 `answerSource` 是「未能确认」 | 自相矛盾，说明答案是自己编的 |
| `answerSource` 是「老师定案」但照片上老师只写了 ✗ | **来源造假**——这是最严重的一种 |
| 孩子答案与正确答案完全相同 | 多半是把孩子的答案抄成了标准答案 |
| `causeNote` 只有「粗心」两个字 | 没有落到具体一步，等于没判 |
| `confidence` 是 `high` 但照片某处明显模糊 | 高置信度却是糊的，多半在装懂 |

## 拍照的两个技巧

1. **一题一张**，把题目四边都拍进去（不要只拍题干中间，条件常在边上）。
2. 光线均匀、不要有阴影——**红笔在阴影里会被看成黑笔**，判错的基础就没了。

## 什么时候该整条退回重做

- 题目本身就不是错题（孩子全对却被收了）
- 题面与照片内容对不上（可能是张冠李戴）
- 拿不到正确答案，也没有留「未能确认」

**退回不是失败，收错才是。**
