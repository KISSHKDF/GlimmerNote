# 数学 · 学科补充

## 转录

- **公式照原样**，不要转成 LaTeX，也不要"美化"。原卷 `y=k/x` 就写 `y=k/x`，不要写成 `y = k ÷ x`。
- **分数线、根号、上下标**：能线性表达就线性表达（`√3`、`x²`、`1/2`），**必须保证无歧义**。
  线性化会产生歧义时（比如 `1/2x` 到底是 `1/(2x)` 还是 `(1/2)x`），用括号消歧。
- **图形题**：`hasFigure: true`。如果图形无法用文字完整表达，在 `notes` 写「依赖原图，请对照照片」。
- **数据表**：逐行照抄，不要省略行列。

## 判错

- 只看最终答案给分是不够的：**过程错但答案对**（凑数、代答案回去验）也是错，按 `L2` 或 `S5` 记，并在 `causeNote` 写清哪一步错。
- **多解题漏解**：答案只写一半（如 `x=1` 漏掉 `x=2`）算错，按 `L1`（分类不全）或 `K4`（忽略条件）记。
- **符号**：加減号、正负号处理错 → `S1`；符号法则/去括号法则本身用错 → `K2`。
- **单位**：漏写单位 → `S5`；单位换算错 → `S1`。

## 错因判断要点

| 现象 | 更可能是 |
|---|---|
| 结论对但完全没有推导 | `L2`（推理断链） |
| 知道方法但算错一步 | `S1` / `S3` |
| 定理/公式用错、定义记混 | `K1`–`K3` |
| 题目条件读漏（"至少""不超过""整数解"） | `S2` |
| 分类讨论只写了一种情况 | `L1` |
| 变形后丢解/增解 | `L3` |

## 常见误判（要避免）

- 把「答案对但过程缺依据」判成对 → 错，应记 `L2` 或 `S5`。
- 把「孩子写得很整齐但思路反了」判成 `S5` → 再想一步，多半是 `K1`。
- 把「题目本身印错」记成孩子的错 → 错，应放进 `notes` 说"原卷疑似印错"。
