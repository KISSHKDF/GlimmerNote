# 语文 · 学科补充

## 转录

- **默写题逐字照抄**，包括孩子写的**错别字**——错在哪个字是这条记录的核心信息。
- **古诗文**：题目、作者、朝代照原样；标点按原卷。
- **"加点字""着重号"必须在题面里标出来**：用 `<span class="rd">字</span>` 包住被标注的那个字。
  这类标记是题目条件，缺了这道题就做不了。
- **阅读理解**：需要上下文的，把相关段落或文章标题一并转录（不要只抄一个问题）。
- **作文**：题面（含要求、字数限制）照抄；正文不入 `questionText`。

## 判错

- **默写错别字**（同音字、形近字） → `K1`（记混）或 `S4`（笔误），在 `causeNote` 写清是哪个字。
- **漏句/漏字** → `K3`（记不全）或 `S4`。
- **古诗文理解题**：只用现代汉语意译、没有落回原文关键句 → `L2`。
- **答题不规范**（问"为什么"只答结论、不分条、不引原文） → `S5`。
- **作文审题**：偏离题意/漏写要求 → `K1` 或 `S2`（漏看要求）。
- **整题空白** → `studentAnswer` 写「未作答」，`notes` 说明"未作答，无法归因"。

## 错因判断要点

| 现象 | 更可能是 |
|---|---|
| 默写错一个字 | `K1` / `S4` |
| 默写整句背不下来 | `K3` |
| 阅读理解答得空泛、不引原文 | `L2` |
| 作文偏题 | `K1` / `S2` |
| 答题格式不规范 | `S5` |

## 常见误判（要避免）

- 把「默写错别字」判成 `S4`（笔误）→ 先看是否是同音/形近混淆；系统性混淆按 `K1`。
- 把「答题要点对但表述口语化」判错 → 先看该题是否要求书面规范；不要求按对处理。
- **漏标加点字** → 必须在 `notes` 明确提示"原卷有加点字，需补标记"，否则重做卷会缺条件。
