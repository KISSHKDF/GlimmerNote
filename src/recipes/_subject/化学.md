# 化学 · 学科补充

## 转录

- **化学式与上下标照原样**：`H₂O`、`CO₂`、`SO₄²⁻`、`Fe³⁺`，下标和电荷位置都是信息。
- **反应条件写在箭头上下**：`2H₂ + O₂ --点燃--> 2H₂O`，条件（点燃/加热/催化剂）不能省。
- **配平系数照抄**，包括孩子写错的系数。
- **实验装置图**：`hasFigure: true`，`notes` 写清仪器名称与连接顺序。
- **表格与现象描述**：逐行照抄，"产生气泡""溶液变蓝"这类现象原文保留。

## 判错

- **化学式写错**（元素符号大小写、下标漏） → `K3`。
- **方程式没配平** → `K2`（法则误用）或 `S3`（跳步），视是否系统性。
- **漏写反应条件/气体↑/沉淀↓符号** → `S5`。
- **概念混淆**（质量守恒 vs 原子守恒、物理变化 vs 化学变化） → `K1`。
- **计算题单位/摩尔关系错** → `S1` 或 `K3`。
- **实验题答"现象"却写成"结论"** → `S5`（答题不规范），`causeNote` 说明。

## 错因判断要点

| 现象 | 更可能是 |
|---|---|
| 元素符号大小写错、化学式下标错 | `K3` |
| 方程式系数不对 | `K2` / `S3` |
| 漏标条件、↑↓ | `S5` |
| 概念边界混淆 | `K1` |
| 计算时物质的量关系用错 | `K3` / `S1` |

## 常见误判（要避免）

- 把「条件符号漏写」判成 `K2` → 那是法则用错；先按 `S5`（书写规范）。
- 把「孩子用了不同但等价的方程式」判错 → 若配平与守恒成立，按对处理，`notes` 说明。
