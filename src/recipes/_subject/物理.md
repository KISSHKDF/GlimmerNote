# 物理 · 学科补充

## 转录

- **公式与单位照原样**。`ρ=m/V`、`W=Fs`、`η=W有/W总` 直接写，不要转成 LaTeX。
- **下标是信息**：`W有` / `W总` / `R1` / `U额` 这类下标必须保留，不能合并成 `W`。
- **数值必须带单位**，原卷没写单位也要在 `notes` 注明「原卷未写单位」。
- **电路图/受力图/实验装置图**：`hasFigure: true`，并在 `notes` 写清图里有哪些元件/方向，便于重画。
- **实验数据表**：逐行照抄，包括表头的物理量与单位。

## 判错

- **只写数值不写单位** → `S5`。
- **代入时把单位丢掉或换算错**（cm 当 m、g 当 kg）→ `S1`。
- **公式用对了但字母代错**（`m` 与 `G` 混、`v` 与 `V` 混）→ `K2`。
- **忽略隐含条件**（"匀速"→合力为零、"静止"→受力平衡、"薄壁"→不计容器重）→ `K4`。
- **多情况漏分析**（滑动变阻器滑到两端、串联/并联两种可能）→ `L1`。
- **有效数字/估算题**只写结论不写依据 → `L2`。

## 错因判断要点

| 现象 | 更可能是 |
|---|---|
| 公式对、数代错、算错 | `S1` / `S3` |
| 公式本身记错（写成 `ρ=mV`） | `K3` |
| 概念混淆（质量/重力、功率/效率） | `K1` |
| 漏看"不计摩擦""轻质"等条件 | `K4` |
| 电路两种接法只算一种 | `L1` |

## 常见误判（要避免）

- 把「单位漏写」判成 `K1` → 不是概念问题，是 `S5`。
- 把「孩子没写公式直接给答案」判成对 → 视要求而定；若题目要求写依据，记 `S5`。
- 把「物理量符号写错但意思对」直接判错 → 先看该题是否要求规范书写，`notes` 写清。
