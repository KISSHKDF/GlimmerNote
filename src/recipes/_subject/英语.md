# 英语 · 学科补充

## 转录

- **大小写是信息**。句首大写、专有名词大写、`I` 大写，全部照原样。孩子写错大小写要保留错误形态。
- **标点照原样**，包括漏写的句号、感叹号、问号。
- **拼写错误照抄**，不要"顺手改对"——拼错本身往往是错因。
- **填空题**：`questionText` 要包含空所在的整句，用 `＿＿＿`（或原卷的下划线形态）标出空位。
- **完形/阅读**：如果题目依赖上文段落，把必要的上下文一并转录（不要只抄一个空）。
- **听力/对话**：若画面里有对话气泡，按说话人顺序转录。

## 判错

- **语法正确但不符合课文/教材原句** → `K5`（固定搭配记错）或 `S5`（不规范），在 `causeNote` 写清是"课文原句是 X"。
- **意思对但词形错**（单复数、时态、词性） → `K6`。
- **语序照中文直译** → `K7`。
- **漏译/漏写成分**（并列结构缺一半、从句缺引导词） → `L4`。
- **同一个空里有两处错** → 仍然只记一条，`causeNote` 逐处列出（"① … ② …"）。
- **作文/书面表达**：整题空白 → `studentAnswer` 写「未作答」，`causeCode` 用 `S5` 并在 `notes` 说明是整题未写而非不会写。

## 错因判断要点

| 现象 | 更可能是 |
|---|---|
| 单词拼错、时态形式错 | `K6` |
| 介词/搭配用错 | `K5` |
| 副词位置、疑问句语序错 | `K7` |
| 并列句/从句缺成分 | `L4` |
| 中文直译导致不合英文习惯 | `K7` 或 `K5` |

## 常见误判（要避免）

- 把「大小写错」判成 `K1` → 不是概念问题，按 `S5`（书写规范）或 `K6`（词形）记。
- 把「孩子答案与标准答案同义但表述不同」判成错 → 先确认题目是否要求"照课文原句"；不要求的按对处理，或记 `S5` 并说明。
- 把「整题没写」判成 `K` 系 → 没写无法判断会不会，`notes` 必须说明"未作答，无法归因"。
