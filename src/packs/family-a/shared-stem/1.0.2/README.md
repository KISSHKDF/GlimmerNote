# 经验包 · family-a/shared-stem 1.0.2

> 来源：从内置配方的反例 **B-07「同一道题拆成两条」** 提炼出来的**试点包**。
> 只补一件事：**整页拆分时，裁图区域怎么定**。B-07 的基本保护留在内置配方里，不搬进包。

## 包里有什么

| 路径 | 是什么 |
|---|---|
| `pack.json` | 包清单：`formatVersion=1`、`id=family-a/shared-stem`、`version=1.0.2`、卡与案例的指引 |
| `cards/shared-stem.md` | 唯一的卡：方法正文（会进提示词） |
| `cases/shared-stem/input.svg` | 合成案例：一页实验题，(1) 已答对、(2) 错且依赖公共题干 |
| `cases/shared-stem/expected.json` | 该案例的期望：收 (2)、(1) 的条件进「公共条件」，以及两个对照 |
| `README.md` | 本文件 |

案例是**自造题面**（合成 SVG），不含任何真实姓名、学校、班级，也不含本机路径。

## 怎么装（首版＝手工复制，没有安装命令）

把这个目录（`1.0.2` 这一层）复制到经验包根下面，保持路径形状：

```
<经验包根>\family-a\shared-stem\1.0.2\
```

经验包根的三档解析（与 `src\tools\_经验包.mjs` 的 `packsRoot()` 同一份实现）：

1. 显式 `--packs <dir>`（最高优先，测试都用它）
2. 环境变量 `CTB_PACKS`
3. 默认 `%LOCALAPPDATA%\拾光小册\经验包\`

装完自检：

```
node src\tools\_经验包.mjs 清单
node src\tools\_经验包.mjs 校验 <经验包根>\family-a\shared-stem\1.0.2
```

## 怎么选它

选卡串（`_配方.mjs 组装 --card <选卡串>`，壳层也按同一条形状判据校验）：

```
family-a/shared-stem/shared-stem@1.0.2
```

## 怎么停（停用即回退）

在 `1.0.2` 目录里放一个 `.停用` 文件（内容写停用原因，随意），之后再用这张卡就会 exit 2 并说明原因；
删掉这个文件立刻恢复。**不需要卸载、不需要别的动作。**

## 怎么改内容

**不要**在同一个 `1.0.2` 目录里改内容——版本号就是内容的身份，改内容必须新建版本目录
（如 `1.0.3`）与新 `pack.json` 的 `version` 并列留存。改了却沿用旧版本号，`校验` 会报「同版异内容」
并给出两侧摘要，因为那时已经说不清装的是哪一份、回退又退到哪一份。
