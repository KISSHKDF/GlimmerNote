# 整页实验题：只登记错的小问，但区域要带全它的解题条件

本卡只解决**一件事**：确认"这一页只收哪一个（哪几个）小问"之后，**怎么定裁图区域**。

> 边界（单一真源）：**"同一道题拆成两条"的基本保护留在内置配方里**（`ingest-page` 的 B-07），
> 那是所有任务都该有的底线，不能靠装经验包才有。本卡只补内置配方没有的部分——区域语义。

## 什么时候用

一页里有多个小问，且同时满足：

- 只有部分小问被判错（其余全对）；
- 错的那个小问**自己文本里条件不全**，要回看本页的公共题干 / 数据表 / 装置图才解得出来。

## 做四步

1. **先定"收哪几个小问"**（内置配方已管，这里只复核一遍）：只收错的小问。
   写在 `source` 里，例如 `第12题(2)`；全对的小问不收，也不作为独立记录存在。

2. **给每个要登记的小问定两类区域**，各自一个区域对象（归一化 `x/y/w/h`，角色按台账户籍写）：

   | 角色 | 圈什么 | 判据（遮掉它还能不能复算） |
   |---|---|---|
   | `错误位置` | **该小问自己的**题干 + 作答 + 批改痕迹（红笔叉/圈/分数） | 遮掉它就看不出错在哪 ⇒ 必须圈 |
   | `公共条件` | 该小问解题**必需**、但不在它自己文本里的条件：公共题干、数据表、装置图、跨页引用的前文 | 遮掉它就算不出正确答案 ⇒ 必须圈 |

3. **坐标一律归一化**：相对**这一页原图自身像素**，`0 ≤ x ≤ 1`、`0 ≤ y ≤ 1`、`0 < w ≤ 1`、`0 < h ≤ 1`，
   且 `x + w ≤ 1`、`y + h ≤ 1`。同时必须写出 `imgW` / `imgH`（算这组坐标时原图的显示宽高）
   与 `pageSha`（这页原图的内容 sha256）——缺任一，坐标就不可复算，等于没写。

4. **一个区域一件角色**：同一个矩形不要既当"错误位置"又当"公共条件"。
   两件事在契约里是两件不同的事，合起来写会让复核的人分不清哪个是"错"、哪个是"条件"。

## 三条反边界（每条都对应一次真实误收）

- **不扩大成整页**：把整页圈进"错误位置"＝退回"整页截图"，看的人仍然要靠翻原图定位错在哪。
  区域的用途是让这条记录**脱离原页也能读懂**。
- **小问互不依赖时不扩大**：如果 (2) 自带全部条件、与 (1) 无关，就**不要**顺手把 (1) 的题干或
  邻题圈进来凑"完整性"。多圈一块=凭空引入无关条件，读的人会以为它是必需的。
- **条件在没提供的页面上 ⇒ 标「待确认」**：下一页没给、图没拍全、字被裁掉，都**不猜、不补**。
  把该区域标成「待确认」，在 `notes` 里写清"缺哪一部分、为什么缺"，交给人看一眼。
  想象出来的坐标比没有坐标更坏：它看起来是证据。

## 为什么（后果，不是规则）

- 区域**太大**：整页都能看懂，但"错在哪一处"没被指出——复核只剩翻原图这一条路，
  "不用原图也能看懂"这个目标当场落空。
- 区域**缺公共条件**：离开原页就读不懂（数据表没截进来、公共题干没截进来），
  复核的人只能放弃或者去猜，记录因此不可信。
- 区域**凭空补**：看起来完整，实际是把想象写成了坐标；这类错误无法被任何自动判据发现，
  只能靠"缺就标待确认"这条纪律挡住。

## 自检（交任务前自己过一遍）

- [ ] 每个登记的小问都有一条 `错误位置`，且只圈它自己那一段
- [ ] 逐个小问问过"遮掉公共条件还能复算吗"，需要才加 `公共条件`
- [ ] 所有区域都有 `imgW` / `imgH` / `pageSha`，且 `pageSha` 是**这一页原图**的 sha256
- [ ] 没有把整页、邻题、无关条件圈进来
- [ ] 缺条件的地方写的是「待确认」+ 原因，不是猜出来的坐标
