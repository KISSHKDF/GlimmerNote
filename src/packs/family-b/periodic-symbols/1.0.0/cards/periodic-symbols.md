# 卡：写化学式之前，先把题给的条件列成一张小表

> 这张卡是**跨学科复用**同一条方法的结果（内置配方里的通用底线不动，本卡只补化学这一科需要的那部分）。

## 什么时候用（适用条件）

**同时**满足两条才用：

1. 题面把条件**分散**给出（多行、多栏，或一张表格里夹在别的信息中间）；
2. 这些条件对**多个**小题都必需（不是某一小题自己带的）。

只满足一条就别用：条件只服务一个小题时，直接把该小题需要的量写进它的 notes 即可；
条件已经集中在题首、一眼能找到时，**再加一张表是重复劳动**。

## 步骤

1. **先扫题面，把"只出现一次、但后面还要用"的条件挑出来**——化学里通常是：常见化合价、原子团及其价态、相对原子质量、以及"按什么规则书写"这类要求。
2. **把它们合并成一张小表**（写进记录字段，不是画在卷面上）：一行一类，值写全，来源写清是"题给"还是"背下来的"。
   来源必须区分：题给的可引用；背下来的属于**你自己的知识**，不能冒充题面事实。
3. **写每个化学式时逐项对照这张表**：先定正负价，再算最小公倍数定下标，**原子团要整体括起来**（如 `(SO₄)`、`(OH)`）。
4. **区域怎么圈**（区域契约见 `docs\区域契约.md`）：
   - 「错误位置」= **只圈错的那一个小问自身**（题干 + 作答 + 批改痕迹）；
   - 「公共条件」= 那张只出现一次、且这一小题也必需的表；
   - 两者都必须是**卷面事实**。**"为什么错"不进区域**，进 `causeNote` / `notes`。
5. **批改痕迹只有符号时**（真实卷面的常态：一个叉、一个分数、一个圈）：区域照旧只圈该小题自身，
   但 `causeNote` 必须写清错因与正确解法 —— 否则脱离原页读不懂（这一条的实测依据见 family-a 那张卡的家长判断）。

## 反例（能发现误伤）

- **把「公共条件」那张表也圈进「错误位置」**：看起来"更完整"，实际是误伤 —— 复核的人会以为错在表格上。
  判据见本包案例 `cases/periodic-symbols` 的对照 `public-condition-marked-as-error`。
- **条件在没提供的下一页**：不许按想象补坐标，标「待确认」并写清缺什么（对照 `condition-on-next-page`）。
- **小题自带全部条件却还追加「公共条件」区域**：无谓扩大区域（对照 `independent-subquestion`）。

## 自检清单

- [ ] 这张表里的每一条，都说得清**是题给还是我背的**？
- [ ] 每个化学式的下标，都能在这张表上一步步对出来？
- [ ] 原子团整体括起来了吗（`(SO₄)` / `(OH)` / `(NO₃)`）？
- [ ] 区域里只有卷面事实，没有"为什么错"？
- [ ] 批改只有符号时，`causeNote` 写清错因与正确解法了吗？
